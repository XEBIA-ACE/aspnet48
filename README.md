# My .NET Framework 4.8 Web Application

## Overview
This is a sample ASP.NET Web Application built using .NET Framework 4.8.

## Features
- REST APIs
- Service Layer + Repository Pattern
- Dependency Injection
- Swagger Integration

## 🛠️ Tech Stack
- .NET Framework 4.8
- ASP.NET Web API
- SQL Server
- Unity DI

## ▶️ How to Run
1. Open solution in Visual Studio
2. Restore NuGet packages
3. Run the project

## 📂 Project Structure
- Controllers/
- Services/
- Repositories/
- Models/
